# Travelgram ✈️📸

O **Travelgram** é uma landing page responsiva que simula o perfil de uma rede social focada em viagens e fotografia. O projeto foi desenvolvido como um portfólio pessoal para a viajante Isabella Torres, exibindo suas estatísticas de viagem e uma galeria de fotos marcantes de suas aventuras pelo mundo.

---

## 🚀 Funcionalidades

* **Cabeçalho de Navegação:** Barra superior funcional com a logo do projeto, campo de busca ("Explorer") e link para viagens.
* **Perfil do Usuário:** Seção com foto de perfil, biografia detalhada e localização atual.
* **Contadores de Engajamento:** Exibição dinâmica de dados (número de países visitados e total de fotos publicadas).
* **Galeria de Fotos Estilizada:** Grid responsivo exibindo 12 fotos de alta qualidade de destinos turísticos icônicos (como Veneza, Roma, Florença, entre outros).
* **Rodapé Institucional:** Links para Termos de uso e Termos de privacidade.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando práticas modernas de desenvolvimento web front-end:

* **HTML5:** Estruturação semântica de toda a página.
* **CSS3:** Estilização, layout e posicionamento dos elementos.
    * **Flexbox & CSS Grid:** Utilizados para criar o alinhamento do cabeçalho e a disposição responsiva da galeria de fotos.
    * **Google Fonts:** Integração de fontes modernas e limpas para melhorar a legibilidade.
